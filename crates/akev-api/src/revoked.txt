# Akev Pro licence ids that no longer unlock new builds: fully refunded purchases and
# charged-back purchases (open or lost chargebacks; inquiries and won disputes don't count).
# A licence id is the purchase's PaymentIntent id. Builds released earlier keep accepting the
# key: the check runs offline, against the list compiled into each build.
# Generated from Stripe by `bun licensing/cli.ts revoked` in the website repository, which
# scripts/release.sh runs for every release, so changes made here by hand don't survive it.
# Stripe live mode.
